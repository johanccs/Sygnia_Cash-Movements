Sygnia

A production-grade cash-movement backend, built as a C# / .NET take-home assignment

What this is

Sygnia is a small but production-shaped banking backend: a gRPC service backed by EF Core and SQL Server, with an Angular front end talking to it over gRPC-Web. It records cash movements against accounts, transfers money between accounts atomically, reports balances, and streams full account statements — built to demonstrate two properties that matter in a real financial system: safe handling of duplicate/retried requests, and statements that never load an unbounded result set into memory.

gRPC .NET 8 EF Core SQL Server Angular 18 Clean Architecture Testcontainers

Two things this system gets right

  • Idempotency lives in the database. A composite primary key (AccountId, ExternalRef) is the idempotency mechanism — repeated submissions of the same movement are detected and handled safely, even under concurrent load.
  • Statements stream end to end. Account statements are read and sent one row at a time, from the database through to the client, so an account with tens of thousands of movements never gets loaded into memory all at once.
